DeepSeek 官方 API 调研报告

调研主题：DeepSeek 官方 API 的模型、上下文长度与价格  |  数据来源：DeepSeek 官方文档（api-docs.deepseek.com） |  调研时间：2026-08

一、调研概述

本报告基于 DeepSeek 官方 API 文档《Models & Pricing》页面进行联网抓取与整理，汇总了当前官方开放 API 的模型名称、上下文长度、最大输出长度以及分时段的输入/输出定价，并附上使用成本方面的简要结论。所有价格均以「每 1M tokens」为单位计量。

二、模型与基本参数

当前 DeepSeek 官方 API 共提供 3 个模型（含 1 个视觉实验模型）：

  • deepseek-v4-flash — 通用对话/推理模型，支持思维模式与非思维模式，支持 FIM（非思维模式）等。
  • deepseek-v4-pro — 高阶专业模型，性能更强，支持思维模式与非思维模式，支持 FIM（非思维模式）。
  • deepseek-v4-flash-vision-exp — 视觉实验模型，可同时处理图片与文本，不支持 FIM。

三个模型均同时支持 OpenAI 兼容格式（https://api.deepseek.com）与 Anthropic 兼容格式（https://api.deepseek.com/anthropic），并支持 JSON 输出、工具调用、Responses API、Anthropic API 及 Chat Prefix（Beta）等功能。

四、价格明细（每 1M tokens，单位 USD）

DeepSeek 采用高峰 / 低谷分时计价：高峰时段为周一至周五 UTC 01:00–04:00 与 06:00–10:00，其余时间为低谷；低谷价为高峰价的一半。计费基于「Token 数 × 单价」，直接从余额扣费，若同时有赠送额度与充值余额，优先扣赠送额度。

五、调研结论

1. 模型梯度清晰。 DeepSeek 官方当前提供 V4 系列三条 API 产品线：Flash（高速通用）、Pro（专业高性能）与 Flash-Vision（视觉实验），三者共享 1M 超长上下文与 384K 最大输出，覆盖从轻量对话到多模态长文本的多种场景。

2. 定价策略分层明显。 整套价格呈现「输出 > 输入未命中 > 输入命中」的梯度，配合高峰/低谷时段差异化计价（低谷为高峰一半），鼓励用户在非高峰时段调用以降低成本；同时缓存命中可实现近 30～60 倍的输入成本下降。

3. Pro 定位更高。 无论输入命中、未命中还是输出，Pro 的价格基本是 Flash 的 3 倍（低谷 $0.022 vs $0.007 等），但其并发上限（500）低于 Flash（2500），更适合对性能要求高、调用量平稳的生产环境。

4. 成本估算参考。 以 Flash 低谷价为例，输入缓存未命中 $0.22 /1M、输出 $0.66 /1M，即处理百万级 token 的输入+输出合计成本约为 $0.88；总体而言 DeepSeek API 在同等上下文规模下具备较强的性价比。

本报告数据全部来自 DeepSeek 官方文档页面（https://api-docs.deepseek.com/quick_start/pricing），官网保留调整价格之权利，建议以官方页面最新信息为准。
