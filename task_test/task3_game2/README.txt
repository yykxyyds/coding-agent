植物大战僵尸 Demo（tkinter 版）
================================

一个用 Python 内置 tkinter 编写的植物大战僵尸精简复刻，无需安装第三方库即可游玩。

运行方式
--------
    python pvz_demo.py

（需要本机已装 Python，tkinter 为标准库自带。）

游戏玩法
--------
1. 游戏开始先在草地区种植植物（按 1~5 键或点击卡片选择植物）。
2. 点击"开始/下一波"按钮放出僵尸，之后每清空一波再点一次进入下一波，共 5 波。
3. 用豌豆射手等攻击型植物消灭僵尸，用向日葵收集阳光购买更多植物。
4. 坚持到所有波次僵尸被消灭即胜利；若任何僵尸走到最左边房子，则失败。
5. 游戏支持随时暂停；失败/胜利后可点"重新开始"再来一局。

操作方式
--------
- 数字键 1/2/3/4/5：选择卡片（向日葵 / 豌豆射手 / 寒冰射手 / 坚果墙 / 樱桃炸弹）
- 鼠标左键：选择卡片后点击草地格子种植；点击掉落/产出的阳光可收集
- 点击"铲"按钮后再点植物：铲除植物；也可用鼠标右键直接铲除
- 鼠标左键点击卡片栏：选择对应植物
- "暂停"按钮：暂停/继续游戏

植物说明
--------
| 植物      | 阳光 | 功能                                    |
|-----------|------|-----------------------------------------|
| 向日葵    |  50  | 周期性生产阳光                          |
| 豌豆射手  | 100  | 向前发射豌豆攻击僵尸                    |
| 寒冰射手  | 175  | 发射冰冻豌豆，攻击并减速僵尸            |
| 坚果墙    |  50  | 高血量，阻挡僵尸前进                    |
| 樱桃炸弹  | 150  | 种植后延时爆炸，范围伤害附近僵尸        |

僵尸说明
--------
| 僵尸      | 血量 | 速度    | 说明                 |
|-----------|------|---------|----------------------|
| 普通僵尸  | 100  | 0.35    | 最常见               |
| 路障僵尸  | 250  | 0.28    | 更耐打               |
| 铁桶僵尸  | 450  | 0.22    | 非常耐打、较慢       |

技术说明
--------
- 5 行 × 9 列草地，窗口 930×540
- 帧刷新率 60 FPS，逻辑与渲染分离在 _tick 主循环中
- 所有图形用 tkinter Canvas 矢量绘制，无外部图片素材
